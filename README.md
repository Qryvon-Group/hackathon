# ⚡ QRYVON SYNC '26 | Official Starter Kit

Welcome to **Qryvon Sync '26**. This repository serves as the official boilerplate workspace for your hackathon submission. 


## 🛠️ Quick Instructions for Teams
1. **Fork this repository** into your team leader's personal GitHub account or organization.
2. Rename the forked repository to match your team name (e.g., `axiom-sync-TeamAlpha`).
3. Invite your teammates as collaborators so you can code together in real-time.
4. **Important:** Ensure your final code is pushed to your public repository before the deadline.


## 📂 Suggested Project Structure
Depending on what track you chose, keep your files organized:
- `/src` -> Source code (HTML/JS, Python, React, etc.)
- `/assets` -> Game sprites, textures, or UI mockups
- `/docs` -> Pitch deck, architecture diagrams, or project notes
